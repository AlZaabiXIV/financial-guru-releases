# The Financial Guru · المرشد المالي

Download page for **The Financial Guru**, your personal financial guru.

➡️ **[Latest version](../../releases/latest)**

- **Windows:** download `FinancialGuru-Setup-<version>.exe` and run it.
- **Android:** download `FinancialGuru-<version>.apk` on your phone and open it.

Once installed, both apps update themselves: open the app and tap **Update** when a new version is ready.

This repository only holds the finished installers. The app's source code is private.
